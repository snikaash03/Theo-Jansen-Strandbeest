# 🦿 Theo Jansen Strandbeest Mechanism

## Overview

This project focuses on designing and analysing the famous Theo Jansen Strandbeest walking mechanism using Fusion 360 and Python.

The mechanism converts rotational motion into a stable walking gait using a system of interconnected linkages. Along with the CAD model, Python was used to perform kinematic analysis and study the motion of the mechanism.

## Why This Project?

The Theo Jansen Strandbeest is a fascinating example of biomimetic engineering, where a system of mechanical linkages produces a natural walking motion without the need for complex control systems.

We chose this project to better understand linkage mechanisms, kinematic motion, and CAD assembly design while exploring how rotational motion can be transformed into an efficient walking gait.

## Software & Tools

- Fusion 360
- Python
- NumPy
- Matplotlib
